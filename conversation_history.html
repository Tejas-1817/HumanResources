Antigravity (AI Assistant)

Ah, that is a classic React event bubbling issue! Here is what's happening and how to fix it:

The Explanation (Why this happens)

In HTML and React, when you click an element (like a checkbox), the browser triggers a click event. This click event bubbles upwards to all parent containers. Since the parent div has onClick={() => navigate(...)} to open the candidate details, clicking the checkbox triggers the parent's click event first and navigates away.

Even though we wrote e.stopPropagation() in the onChange event, onChange is a separate event from click and does not stop the click event from bubbling up.

The Fix

To stop the navigation, we need to explicitly stop the onClick event on the checkbox itself.

Please open your [Archives.tsx](file:///c:/Users/admin/Desktop/HumanResources_New/HumanResources/HumanResources/frontend/src/pages/Archives.tsx) file. We need to update the two checkboxes (one for mobile and one for desktop).
