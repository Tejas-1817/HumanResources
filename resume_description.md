## Option 2: Detailed Bullet Points (For Experience Section)

**Project: ResumeIQ (AI-Powered Recruitment Management System)**

*   **Architected and developed** a high-performance, full-stack recruitment platform using **React (Vite)** and **FastAPI (Python)**, enabling seamless candidate tracking and management for multiple partner companies.
*   **Implemented a real-time Kanban pipeline** using **Framer Motion** and **TanStack Query**, allowing recruiters to manage candidate stages (Shortlisted, Interview, Selected) with drag-and-drop functionality and automated status updates.
*   **Engineered a comprehensive analytics dashboard** using **Recharts**, providing real-time insights into talent DNA (skills trending), hiring performance (conversion rates), and recruitment funnel health.
*   **Designed a scalable Partner Hub** to manage multi-tenant recruitment operations, including complex relational data handling for job roles, candidates, and client companies using **SQLAlchemy** and **SQLite**.
*   **Enhanced user experience** by implementing a premium, high-fidelity UI using **TailwindCSS** and **Shadcn UI**, featuring sophisticated dark mode support, glassmorphism aesthetics, and responsive design for all devices.
*   **Developed automated resume processing** workflows that handle file uploads, parsing, and structured data storage, reducing manual entry time by approximately 40%.
*   **Optimized application performance** through efficient data fetching strategies with **React Query**, implementing debounced global search and paginated candidate directories for large datasets.
